# Dataset Sources for SepSentinel

## Current: Synthetic Data

Generated by `sepsentinel/data/synthetic.py`. Produces 500 flat records with 7 features (HR, RR, Temp, SpO2, pH, Lactate, IL-6) for baseline model development.

Not intended for clinical validation. Used to develop the pipeline, test architectures, and debug dashboards.

## Target: MIMIC-IV (Credentialed Access)

### MIMIC-IV Clinical Database
- **Source**: PhysioNet (MIT)
- **URL**: https://physionet.org/content/mimiciv/
- **Access**: Requires PhysioNet account + CITI training
- **Contains**: ICU charted events (vitals, labs) with timestamps
- **Relevant signals**: Heart rate, respiratory rate, temperature, SpO2, pH, lactate
- **Note**: IL-6 may be sparse; plan for handling missing biomarkers

### MIMIC-IV Waveform Database
- **Source**: PhysioNet (MIT)
- **URL**: https://physionet.org/content/mimic4wdb/
- **Access**: Requires PhysioNet account + CITI training
- **Contains**: Continuous physiological waveforms (ECG, PPG, etc.)
- **Use case**: High-resolution physiological signal data

## Supplementary Public Datasets

### MIMIC-IV Style ICU Dataset for Sepsis Prediction
- **Source**: Kaggle (sinanshereef)
- **Access**: Free with Kaggle account
- **Contains**: Synthetic ICU data modeled after MIMIC-IV structure
- **Note**: Flat records, no time series. Useful for flat model baselines only.

## Pipeline Design

The preprocessing pipeline is designed so synthetic and MIMIC data produce the same output format:

```
Raw data source (synthetic / MIMIC)
    -> Episode extraction (patient time series)
    -> Sliding window (configurable: 30min-4hr)
    -> Tensor: (batch_size, timesteps, 7)
    -> Model input
```

Swapping data sources requires changing only the loader, not the pipeline.
