# Dataset Sources for SepSentinel

## Currently Used

### Synthetic Data (built-in)
- Generated by `sepsentinel/data_generator.py`
- 500 patient records (250 healthy, 250 septic)
- Features: Lactate (mmol/L), IL-6 (pg/mL), pH (pH units)
- Useful for development and testing, not for clinical validation

## Recommended Public Datasets

### MIMIC-IV Style ICU Dataset for Sepsis Prediction (Recommended)
- **Source**: Kaggle (sinanshereef)
- **URL**: https://www.kaggle.com/datasets/sinanshereef/mimic-iv-style-icu-dataset-for-sepsis-prediction
- **Access**: Free with Kaggle account, no CITI training required
- **Contains**: Synthetic ICU data modeled after MIMIC-IV structure
- **Features**: Lactate, pH, vitals, lab values, SOFA scores, sepsis labels
- **Note**: IL-6 may not be available; substitute with WBC or CRP if needed

### Sepsis Prediction Dataset
- **Source**: Kaggle (tea340yashjoshi)
- **URL**: https://www.kaggle.com/datasets/tea340yashjoshi/sepsis-prediction-dataset
- **Access**: Free with Kaggle account

### Prediction of Sepsis
- **Source**: Kaggle (salikhussaini49)
- **URL**: https://www.kaggle.com/datasets/salikhussaini49/prediction-of-sepsis
- **Access**: Free with Kaggle account

### Sepsis Survival Prediction (Minimal Clinical Records)
- **Source**: Kaggle (joebeachcapital)
- **URL**: https://www.kaggle.com/datasets/joebeachcapital/sepsis-survival-minimal-clinical-records
- **Access**: Free with Kaggle account

## Datasets Requiring Credentialed Access

### MIMIC-III / MIMIC-IV
- **Source**: PhysioNet (MIT)
- **URL**: https://physionet.org/content/mimiciii/
- **Access**: Requires PhysioNet account + CITI training completion
- **Contains**: Real ICU patient records with comprehensive lab values

### eICU Collaborative Research Database
- **Source**: PhysioNet
- **URL**: https://physionet.org/content/eicu-crd/
- **Access**: Requires PhysioNet account + CITI training completion

## How to Use a Dataset

1. Download the CSV from one of the sources above
2. Place it in the `data/` folder
3. Run `python main.py` and select option [4] (Train from real dataset)
4. The data loader will auto-detect columns and map them to our biomarkers
5. If a column can't be auto-detected, you'll be prompted to select it manually
